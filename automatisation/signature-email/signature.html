Installer la signature

  • Webmail Hostinger : Paramètres → Signatures → collez la signature dans l'éditeur, puis enregistrez.
  • Gmail : Paramètres → Voir tous les paramètres → Signature → Créer → collez.
  • Apple Mail : Réglages → Signatures → décochez « Toujours utiliser ma police par défaut », puis collez.
  • Outlook : Paramètres → Comptes → Signatures → collez.

Le logo est chargé depuis myvisadtv.com : il n'alourdit pas vos e-mails et s'affiche sans pièce jointe. Certaines messageries bloquent les images jusqu'à ce que le destinataire les autorise : le texte reste lisible.
